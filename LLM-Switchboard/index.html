Why Anthropic doesn't work directly in the browser

Anthropic's API blocks direct browser requests via a CORS policy — this is intentional security design. Your API key would be exposed in client-side code, so they require requests to be made from a backend server. OpenAI allows browser requests, which is why the OpenAI panel works here. To use Claude in a real app, you'd add a small server (Node/Python) that forwards requests on your behalf.
